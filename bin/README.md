# Bin Directory

Place the `onezerominer` binary here.

## Download

Get the latest release from:
- https://github.com/EhssanD/onezerominer/releases

## Install

```bash
# Linux x86_64
wget https://github.com/EhssanD/onezerominer/releases/download/v1.8.3/onezerominer-linux-x86_64.tar.gz
tar -xzf onezerominer-linux-x86_64.tar.gz
mv onezerominer bin/
chmod +x bin/onezerominer
```

## Verify

```bash
./bin/onezerominer --help
```
